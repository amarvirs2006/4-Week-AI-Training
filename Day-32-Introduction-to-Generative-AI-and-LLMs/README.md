# What is Generative AI?

Generative AI is a branch of Artificial Intelligence that can generate new content such as text, images, audio, videos, and code based on user input (prompts).

Examples include:

* Chatbots
* Text Generation
* Image Generation
* Code Generation
* Content Summarization

---

# Large Language Models (LLMs)

Large Language Models (LLMs) are deep learning models trained on massive amounts of text data. They can understand natural language, answer questions, generate text, summarize information, and assist with many AI-related tasks.

Examples of LLM providers include:

* Mistral AI
* OpenAI
* Google
* Anthropic

---

# LangChain

LangChain is a Python framework used to build applications powered by Large Language Models. It simplifies connecting LLMs with prompts, external data, memory, and other tools.

---

# Types of AI Models

We discussed the following categories of AI models:

### Chat / Language Models

Used for conversations, question answering, text generation, and summarization.

### Embedding Models

Convert text into numerical vectors that can be used for semantic search, recommendation systems, and Retrieval-Augmented Generation (RAG).

### Multimodal Models

Process multiple types of input such as text, images, audio, or video within the same model.

---

# Prompt Engineering

A **prompt** is the instruction or question given to an AI model.

We discussed different types of prompts, including:

* Zero-shot Prompting
* One-shot Prompting
* Few-shot Prompting

Well-structured prompts help produce more accurate and relevant responses.

This helps protect sensitive credentials and makes the project easier to manage.
